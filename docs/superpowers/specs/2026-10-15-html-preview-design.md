# HTML 文件预览设计

日期：2026-10-15

## 背景

nas-md 当前将 Markdown 文件显示在侧栏并交由 Vditor 打开。服务端已经能按 HTML MIME 类型返回 `.html` 和 `.htm` 文件，但前后端文件树只筛选 Markdown，打开流程也始终初始化 Markdown 编辑器。浏览器本地挂载同样只收录 Markdown 文件。

用户希望在保留现有 Markdown 行为的基础上支持 HTML 文件浏览器预览，并要求页面能加载同目录相对 CSS、图片和 JavaScript 资源。

## 目标

- `.html` 与 `.htm` 文件出现在服务器挂载和浏览器本地挂载的文件树中。
- 点击 HTML 文件后，在应用内独立预览网页内容，而不是将 HTML 源码作为 Markdown 显示。
- 支持挂载目录内的相对资源引用，包括 CSS、图片和 JavaScript。
- HTML 页面在隔离的 iframe 中运行，不能访问 nas-md 主页面，也不能导航出预览框架。
- 保持现有 Markdown 编辑、保存、协同、历史和导出行为不变。

## 非目标

- 编辑或保存 HTML 源码。
- 将 HTML 纳入 Markdown 搜索、知识图谱、反向链接或 Markdown 版本历史。
- 允许预览内容访问 nas-md 主页面的 DOM、存储或脚本上下文。
- 将挂载目录之外的本地文件作为页面资源读取。

## 用户流程

1. 文件树显示 `.md` 文件以及 `.html`、`.htm` 文件。
2. 目录若包含以上受支持文件，或满足现有空目录显示条件，则继续显示。
3. 用户点击 HTML 文件后，应用加载文件正文并显示独立预览；Markdown 文件继续打开 Vditor。
4. HTML 文档引用相对 CSS、图片或脚本时，预览器从同一挂载中解析和加载这些资源。
5. 文件或资源不存在、格式无法读取或加载失败时，预览区域显示可理解的错误状态，并允许返回文件树或打开其他文件。

## 设计

### 文件发现

前端统一使用 HTML 扩展名识别逻辑，覆盖服务器返回的树、File System Access API 遍历结果和 `webkitdirectory` 回退结果。目录的“包含可显示文件”标记由 Markdown 与 HTML 文件共同决定。服务端目录树的标记也需扩展为包含 HTML 文件，以避免服务器树数据和本地树数据的行为差异。

### 打开与显示

`openFile` 在读取文件后根据扩展名分发：Markdown 继续走当前 Vditor 初始化和状态流程；HTML 走独立预览面板。预览面板与 Vditor 相互独立，不将 HTML 文本传入 Markdown 渲染器。HTML 作为只读预览，不启用编辑器模式、自动保存、协同编辑、Markdown 导出或版本历史操作。文件树切换、最近访问和当前文件标题沿用已有应用状态机制。

### 资源解析

预览器以当前文件所在目录作为相对 URL 的根，并将资源访问约束在该文件所属挂载点内。服务器挂载和浏览器本地挂载都应遵守相同的路径语义。预览支持同目录及其子目录中的相对 CSS、图片和 JavaScript；资源请求失败时保留主体页面并报告失败资源。绝对外部 URL 仍由浏览器按正常网络策略处理。

具体资源加载实现可以按挂载类型采用不同的数据读取方式，但不得放宽现有路径安全校验，也不得让资源 URL 逃逸挂载根目录。

### 安全边界

HTML 放入 sandbox iframe。允许页面脚本在 iframe 内执行，以满足 HTML 页面自身的交互需求；不授予 `allow-same-origin`、顶层导航或弹窗权限。iframe 中的内容不能访问父页面 DOM 或同源存储。资源加载及页面脚本失败只影响预览区，不影响 nas-md 主应用。

### 错误处理

- 主 HTML 文件读取失败：显示预览加载失败状态，提供返回/重新打开操作。
- 相对资源缺失或无法读取：页面保持显示，缺失资源按浏览器默认行为处理，并提供可诊断信息。
- 不支持的文件类型继续使用现有提示或行为，不纳入 HTML 预览流程。

## 验收条件

- 服务器挂载与两种浏览器本地目录挂载路径均能发现 `.html` 和 `.htm`，大小写扩展名不敏感。
- 含 HTML 文件的目录能出现在侧栏中；不含可显示文件的非空目录仍遵守当前过滤行为。
- 点击 HTML 显示网页效果；同目录/子目录 CSS、图片、脚本能加载。
- 沙箱页面无法读取父窗口 DOM 或访问父窗口存储，也不能顶层导航离开应用。
- 切换 HTML 与 Markdown 时，Markdown 编辑和保存状态流程保持正确。
- 读取失败和相对资源缺失时应用可继续使用。

## 需覆盖的验证场景

- `.html`、`.htm`、大写扩展名以及嵌套目录文件树。
- 服务端挂载、本机 File System Access API 挂载、`webkitdirectory` 回退挂载。
- 相对 CSS、图片、JavaScript 和缺失资源。
- 沙箱安全属性和 HTML/Markdown 连续切换。
- Markdown 原有只读、可写、自动保存和预览行为回归。
